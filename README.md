# Sales Performance Analysis Project

## Overview
This project analyzes company sales data using Python.

## Tools Used
- Pandas
- Matplotlib
- Seaborn

## Dataset
Synthetic sales dataset with employee, department, and region information.

## Steps Performed
- Created and loaded dataset
- Handled missing values
- Performed group-based analysis
- Visualized employee performance

## Key Insights
- Sales department performs better than HR
- Ayesha is the top performer
- South region shows strong sales performance
